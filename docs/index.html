Biomechanical Acceleration

Break Through Neuromuscular Speed Ceilings

Designed based on motor learning biomechanics to turn sluggish conscious finger reaches into instinctive reflex arcs.

🚀

Ghost Pacer & Real-Time Delta

Visual velocity cursor gliding through text at personal-best or target WPM, paired with a live lead/lag delta badge.

  • Fixed targets: 40, 60, 80, 100, 120, 140 WPM or dynamic Personal Best
  • Instant real-time pace feedback (e.g. ▲ +6.4 WPM / ▼ -3.2 WPM)
  • Smooth character gliding synchronized with precision timers
⚡

Burst & Timed Sprint Engine

Short, explosive rounds that stretch neurological processing speeds before fatigue degradation occurs.

  • 5-word micro-bursts for maximum neuromuscular output
  • 15s, 30s, and 60s timed countdown sprints
  • Infinite streaming text replenishment as you near the end of lines
⏱️

Inter-Key Interval (IKI) Tracking

Measures microsecond latency between consecutive keystrokes (Tlatency = tn - tn-1) to isolate awkward transitions.

  • Classifies transitions: Alternating Hands, Same-Hand Rolls, Same-Finger Leaps
  • Tracks specific weak finger pairs (e.g. Left Ring → Left Pinky)
  • Logs median & average transition speeds across all completed rounds

Sensory Biofeedback in Every Keystroke

Immediate visual and rhythmic cues train your brain to eliminate hesitation pauses and maintain relaxed cadence.

Live On-Screen Keyboard

Real-time virtual keyboard matching your layout with active next-key highlighting and tactile home-row anchor points.

  • Visual opposite-hand Shift chording indicators
  • Home-row anchor points underlined on F and J (or layout equivalents)
  • Compact view for small terminal windows and full matrix for large screens
🔥

Dynamic Thermal Error Glow

Keys heat up upon mistyping and gradually cool down as accurate typing resumes, creating instant peripheral visual awareness.

  • Exponential decay cooling algorithm (λ = 0.15 s-1)
  • Multi-tier glow states: Warm → Heated → Critical Error Red
  • Pinpoints chronic physical reach mistakes instantly
🎵

Cadence & Rhythm Metronome

Live consistency gauge measuring rolling keystroke intervals and coefficient of variation to foster flow-state typing.

  • Real-time state classification: Flow State, Staccato, or Erratic
  • Visual consistency gauge bar with color-graded feedback
  • Encourages smooth, uniform pacing over jerky hesitation bursts

Installation & Setup

Run Yubi in seconds on any Linux, macOS, or WSL terminal.

Download, verify, and run Yubi with a single command:

curl -fsSL https://raw.githubusercontent.com/temesgensida-code/yubi/main/install.sh | bash

Clone and compile from the Git repository (Rust 1.75+ required):

git clone https://github.com/temesgensida-code/yubi.git
cd yubi
cargo run --release

Install binary directly into your cargo bin path:

git clone https://github.com/temesgensida-code/yubi.git
cd yubi
cargo install --path .
