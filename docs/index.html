Yubi TUI Installation & Setup Guide

Quick terminal commands to install, run, and export session data
Step 1

Install Yubi TUI (Automated)

Run this single command in your Linux or macOS terminal. It automatically detects your OS and CPU architecture and installs the yubi binary globally:

curl -fsSL https://raw.githubusercontent.com/temesgensida-code/yubi/main/install.sh | bash
Step 2

Start the Typing Trainer

Once installed, open any terminal window and launch the typing trainer simply by typing:

yubi
Alternative

Build via Rust / Cargo

If you have Cargo installed on your system, you can also install directly from source:

cargo install --git https://github.com/temesgensida-code/yubi
Step 3

Export Session CSV for Visualizer

  1. Launch yubi in your terminal.
  2. Press Tab to switch to the Progress Dashboard view.
  3. Press e to export your practice history to history_export.csv.
  4. Drag & drop your history_export.csv file into this web dashboard!
Location

Where to Access Your Exported CSV File

IMPORTANT CSV FILE LOCATION

The exported CSV file history_export.csv is saved DIRECTLY IN THE EXACT TERMINAL DIRECTORY WHERE YOU EXECUTED THE yubi COMMAND!

Copy file to your Downloads folder for easy browser upload:
cp history_export.csv ~/Downloads/
Open current folder in your Desktop File Manager:
xdg-open . || open .
